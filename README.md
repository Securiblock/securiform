# SECURIFORM

Site vitrine de SECURIFORM, organisme de formation à la sécurité au travail : CACES®, habilitation électrique, secourisme (SST), incendie et évacuation, travaux en hauteur, AIPR, et Vérifications Générales Périodiques (VGP).

Organisme certifié Qualiopi, intervenant partout en France.

🔗 [securiform.fr](https://securiform.fr)

## Stack technique

- [Next.js](https://nextjs.org) (App Router) + [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org)

## Démarrer en local

```bash
npm install
npm run dev
```

Le site est ensuite disponible sur [http://localhost:3000](http://localhost:3000).
